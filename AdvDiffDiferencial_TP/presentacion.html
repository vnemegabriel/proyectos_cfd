Método de las Características

1. Ecuación Reducida y Condiciones
Hipótesis: ν = 0 , S = 0 , ∇ ⋅ v = 0 (incompresible).
Condición inicial: u ( x , 0 ) = u 0 ( x )
∂ u ∂ t + c ∂ u ∂ x = 0
2. Regla de la Cadena
Buscamos una curva x ( t ) tal que la EDP sea una EDO:
d u d t = ∂ u ∂ t + d x d t ∂ u ∂ x
3. Sistema Característico e Integración
d x d t = c ⇒ x ( t ) = c t + x 0
d u d t = 0 ⇒ u = u 0 ( x 0 )
4. Solución General Analítica ( x 0 = x - c t )
u ( x , t ) = u 0 ( x - c t )

Interpretación Física

  • Transporte Rígido
    El perfil u 0 viaja intacto. Se desplaza a la derecha si c > 0 , y a la izquierda si c < 0 .
  • Perspectiva Lagrangiana
    Moviéndose con el fluido, la derivada material es nula ( d u / d t = 0 ). La partícula conserva su concentración original.
  • Perspectiva Euleriana
    En un punto fijo, la variación temporal se equilibra exactamente con el gradiente espacial arrastrado por la corriente.
  • Preservación de la Forma
    No hay ensanchamiento por ausencia de difusión ( ν = 0 ), y no hay estiramiento al ser incompresible ( ∇ ⋅ v = 0 ).
